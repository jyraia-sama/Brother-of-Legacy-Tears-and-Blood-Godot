# Images optionnelles pour les nouveaux modes (à générer avec ChatGPT)

Dès qu'un fichier est déposé au bon endroit (même nom exact), le jeu l'utilise automatiquement.

Format conseillé : **1672 x 941** (16:9), PNG, style dark fantasy peint, **sans texte ni interface** dans l'image.
